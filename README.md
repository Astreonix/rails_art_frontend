# Rails Art Frontend

React (Vite) + Tailwind CSS storefront for Rails Art. Layout follows the Stationers.pk reference: announcement bar, search header, category nav, product cards, cart, COD checkout, and admin catalog tools.

## Run

```bash
cd rails-art-frontend
npm install
npm run dev
```

Set `VITE_API_BASE_URL` in `.env` when the Node/Express API is available. Until then the app runs with local catalog, cart, accounts, and orders.

Admin login: `admin@railsart.pk` / `Admin@123`
